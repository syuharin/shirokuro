# Shirokuro ユーザーマニュアル

Shirokuroは、データベースを一切使用せず、P2P（ピア・ツー・ピア）通信のみで数値をリアルタイム同期するミニマリストな共有ツールです。

---

## 1. クイックスタート（開発者向け）

ローカル環境でアプリケーションを起動する方法です。

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスしてください。

---

## 2. 基本的な使い方

### ステップ1：グループ（ルーム）の作成
1. トップページ（`http://localhost:3000`）にアクセスします。
2. **[Create Group]** ボタンをクリックします。
3. 自動的にユニークなURL（例: `/room/abc-123-xyz`）が生成され、ルームに移動します。

### ステップ2：URLの共有
1. 画面右上の **[Share URL]** ボタンをクリックして、URLをクリップボードにコピーします。
2. 一緒に数値を同期したい相手（最大10名程度）にそのURLを送信します。
3. 相手がそのURLにアクセスすると、自動的に相互接続（P2P）が開始されます。

### ステップ3：表示名の設定
1. **[Display Name]** 入力欄に、あなたの表示名を入力します。
2. 入力した名前は即座に他の参加者の画面に反映されます。
   * ※ 名前は保存されません。ページをリロードするとリセットされます。

### ステップ4：スライダーの同期
1. 画面中央の **スライダー** を左右に動かします。
2. スライダーから指（またはマウス）を離した瞬間に、あなたの数値が全員の画面にブロードキャストされます。
3. 下部の **[Participants]** リストに、全員の最新の数値がリアルタイムで一覧表示されます。

---

## 3. 知っておくべきルール（憲法）

このアプリは以下の原則に基づいて設計されています。

*   **データベースなし**: あなたが入力した名前や数値は、サーバーやデータベースには一切保存されません。ブラウザを閉じるとデータは消滅します。
*   **ログイン不要**: 面倒なアカウント作成やログインは不要です。URLを知っている人だけが参加できます。
*   **P2P通信**: 数値のやり取りは、中央サーバーを介さず、ユーザーのブラウザ間で直接行われます（WebRTC技術）。
*   **ステートレス**: ルームの概念はURLの文字列（ID）のみに存在します。

---

## 4. トラブルシューティング

*   **接続が確立されない**: 
    * ネットワーク環境（ファイアウォールなど）によってWebRTCが制限されている場合があります。
    * ページをリロードしてみてください。
*   **他の人がリストに表示されない**:
    * 全員が同じ正確なURLにアクセスしているか確認してください。
    * 最初にルームを作った人（Lobby-Anchor）がブラウザを閉じると、一時的に接続が不安定になる場合があります。その場合は再接続をお待ちください。
